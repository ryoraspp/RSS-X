# RSS-X

RSSフィードの新着記事を確認し、Xの投稿画面を事前入力した状態で開いて投稿できるWebアプリです。X APIキーは不要です。

## 構成(単一ディレクトリ)

- `server.js` — RSSフィード取得用のExpressサーバー(CORS回避のプロキシ)。本番モードではビルド済みフロントエンド(`dist/`)も配信する
- `src/`, `index.html`, `public/`, `vite.config.js` — React + Viteのフロントエンド
- 開発時はVite開発サーバー(5173番)とAPIサーバー(8787番)を1つのコマンドで同時起動し、`/api` はViteがAPIサーバーへプロキシする

## セットアップ

```bash
npm install
npm run dev   # APIサーバー(8787)とVite開発サーバー(5173)を同時起動
```

ブラウザで http://localhost:5173 を開いてください。

個別に起動したい場合は `npm run dev:api` / `npm run dev:web` も使えます。

## 使い方

1. 「フィード管理」からRSSフィードのURLを追加する
2. 新着記事が一覧表示される(複数フィードは更新日時順にマージ)
3. 記事の「𝕏 に投稿」ボタンを押すと、タイトルとリンクを入力済みのX投稿画面が新しいタブで開く
4. 内容を確認して実際の投稿はX側の画面で行う(投稿済みとしてマークされる)

## 本番ビルド / デプロイ

```bash
npm run build   # dist/ にフロントエンドを出力
npm start       # server.js が単一プロセス・単一ポートでAPIとフロントエンドの両方を配信
```

`npm start` はポート8787(環境変数 `PORT` で変更可)で、APIエンドポイント(`/api/*`)とビルド済みのReactアプリの両方を1つのサーバーで配信します。任意のNode環境にこのディレクトリごとデプロイするだけで動作します。
